# ffxi-helpers

Windower 4 addons for Final Fantasy XI.

> ## ⬇️ Download
> Each addon is available as a single zip. Click the link, extract it into your Windower `addons/` folder, and load it in game. No other files are needed.

| Addon | Description | Download |
|---|---|---|
| [SkillUp](SkillUp/) | Automates magic skill-up rotations with an in-game settings UI | [SkillUp.zip](https://github.com/arydenbck/ffxi-helpers/raw/main/SkillUp/SkillUp.zip) |
| [Trusts](Trusts/) | Trust sets and trust management | [Trusts.zip](https://github.com/arydenbck/ffxi-helpers/raw/main/Trusts/Trusts.zip) |
| [QuickTrade](QuickTrade/) | Quickly trade items to NPCs, with loop support | [QuickTrade.zip](https://github.com/arydenbck/ffxi-helpers/raw/main/QuickTrade/QuickTrade.zip) |

## Installing

1. Download the addon's zip from the table above.
2. Extract it so the addon folder sits inside Windower's `addons/` directory (for example `addons/SkillUp/skillup.lua`).
3. In game, run `//lua load skillup` (or `trusts` / `quicktrade`).
