# ffxi-helpers

Windower 4 addons for Final Fantasy XI.

| Addon | Description |
|---|---|
| [SkillUp](SkillUp/) | Automates magic skill-up rotations with an in-game settings UI |
| [Trusts](Trusts/) | Trust sets and trust management |
| [QuickTrade](QuickTrade/) | Quickly trade items to NPCs, with loop support |

## Installing

Copy the addon's folder into your Windower `addons/` directory and load it with `//lua load <name>`.
